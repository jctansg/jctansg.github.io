# jctansg.github.io

A collection of personal projects — web apps, utilities and games.

**Live site:** https://jctansg.github.io/

`index.html` is the landing page: a single-file project index that links into each project.

## Run locally

No build step. Either open `index.html` directly, or serve the folder:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Notes

- `index.html` carries its own SEO meta tags and JSON-LD structured data.
- Deploys automatically via GitHub Pages from this repo's default branch.
